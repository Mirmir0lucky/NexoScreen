# NexoScreens 2.0.1-26.2 Source

26.2 uyumluluk sürümü.

## Gereksinimler
- Java / JDK 25
- Paper veya Leaf 26.2
- Nexo
- ProtocolLib
- PlaceholderAPI (opsiyonel)

## Derleme
Windows:

```bat
gradle clean build
```

JDK 25 aktif değilse:

```bat
java -version
gradle -version
```

İkisinde de Java/JVM 25 görünmeli.

Çıktı:
`build/libs/NexoScreens-2.0.1-26.2.jar`
